# TugasKu
TugasKu merupakan sebuah website list tugas sederhana yang dirancang untuk membantu mahasiswa dalam mengelola dan memantau tugas perkuliahan mereka agar lebih terorganisir. TugasKu dirancang sebagai sarana list tugas yang memungkinkan mahasiswa untuk melihat daftar tugas mereka yang perlu diselesaikan, matkul tugas tersebut, tenggat waktu, prioritas tugas mereka, dan status progress tugas tersebut.

Website TugasKu terdiri dari 3 halaman utama, yakni ada Dashboard, Pengelolaan yang berisi daftar tugas mereka, dan Profil.
